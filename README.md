## Deploy on GitHub Pages
1. Create a GitHub repository named `YOUR-USERNAME.github.io` (or use any repository with Pages enabled).
2. Upload the contents of this folder to the repository root.
3. In GitHub: Settings → Pages → deploy from the `main` branch and `/ (root)`.
4. Your public recruiter link will be shown by GitHub Pages.
